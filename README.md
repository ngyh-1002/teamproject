# 🗺️ ROS Map Configuration (`map.yaml`) 설명

이 문서는 ROS(로봇 운영체제)에서 사용하는 **맵 설정 파일(`map.yaml`)**의 각 항목을 설명합니다.  
이 파일은 `.pgm` 형태의 지도 이미지와 함께 사용되며,  
픽셀 좌표를 실제 **월드 좌표(미터 단위)**로 변환하는 데 필요한 정보를 담고 있습니다.

---

## 📁 예시 코드

```yaml
image: map.pgm
resolution: 0.050000
origin: [-6.828606, -9.466283, 0.000000]
negate: 0
occupied_thresh: 0.65
free_thresh: 0.196
````

---

## 📖 항목별 설명

### 🖼️ `image: map.pgm`

* 지도 데이터가 저장된 **이미지 파일 경로**
* 일반적으로 흑백 이미지이며:

  * **검은색(0)** → 장애물(Occupied)
  * **하얀색(255)** → 빈 공간(Free)
  * **회색** → 미확인 영역(Unknown)

---

### 📏 `resolution: 0.050000`

* 한 **픽셀이 실제 거리로 몇 미터인지**를 의미합니다.
* `0.05` → 1픽셀 = 0.05m (5cm)
* 즉, 지도의 해상도를 나타냅니다.

---

### 📍 `origin: [-6.828606, -9.466283, 0.000000]`

* 맵의 **좌하단(0,0) 픽셀**이 실제 좌표계 상에서 어디에 위치하는지 나타냅니다.
* 형식: `[x, y, yaw]`

  * `x`: 원점의 X 좌표 (미터)
  * `y`: 원점의 Y 좌표 (미터)
  * `yaw`: 회전 각도 (라디안 단위, 일반적으로 0)

> 예시: 맵의 좌하단 픽셀(0,0)은 실제 좌표 `(-6.83m, -9.47m)` 지점에 해당합니다.

---

### ⚫ `negate: 0`

* 흑백 반전 여부 설정

  * `0`: 검은색 = 장애물
  * `1`: 반전 (검은색 = 빈공간)
* 대부분의 경우 `0`이 기본값입니다.

---

### 🧱 `occupied_thresh: 0.65`

* 픽셀 값이 **0.65 이상**일 경우 장애물(Occupied)로 인식합니다.
* 즉, 65% 이상 검은색이면 벽으로 판단합니다.

---

### ⚪ `free_thresh: 0.196`

* 픽셀 값이 **0.196 이하**일 경우 빈 공간(Free)으로 인식합니다.
* 즉, 19.6% 이하 검은색이면 통로로 판단합니다.

---

## 📚 정리표

| 항목                | 의미                   | 예시 값                  | 설명                |
| ----------------- | -------------------- | --------------------- | ----------------- |
| `image`           | 맵 이미지 파일             | `map.pgm`             | 흑백 지도 이미지         |
| `resolution`      | 해상도 (픽셀당 미터)         | `0.05`                | 1픽셀 = 5cm         |
| `origin`          | 지도 시작 위치 (x, y, yaw) | `[-6.83, -9.47, 0.0]` | 맵의 실제 좌표계 원점      |
| `negate`          | 색 반전 여부              | `0`                   | 0 = 검은색이 장애물      |
| `occupied_thresh` | 장애물 임계값              | `0.65`                | 65% 이상 검은색 = 벽    |
| `free_thresh`     | 빈공간 임계값              | `0.196`               | 19.6% 이하 검은색 = 통로 |

---

## 🧭 참고

이 설정 파일은 ROS의 `map_server` 노드에서 사용되며,
`ros2 launch`나 `ros2 run map_server map_server` 명령어 실행 시
로봇의 좌표계와 지도 이미지를 일치시키는 역할을 합니다.
